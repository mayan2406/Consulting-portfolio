# Six Sigma DMAIC Case Study
## E-Commerce Delivery Delay Reduction

**Author:** Mayan Sachdeva | M.Sc. Economics, University of Bonn  
**Methodology:** Six Sigma Green Belt — DMAIC  
**Dataset:** E-Commerce Shipping Dataset (Kaggle, ~11,000 shipments)  
**Date:** May 2026

### Overview
Applied full DMAIC framework to identify and reduce delivery delays 
across a multi-warehouse e-commerce network.

### Key Findings
- Baseline late delivery rate: ~60% (DPMO to be inserted after running)
- Top root causes: warehouse block assignment, shipment mode, parcel weight
- Projected DPMO reduction: ≥30% through 4 targeted interventions

### Tools Used
Python, pandas, scipy, statsmodels, matplotlib, seaborn
